OpenAPI → MCP, born instrumented

Give your API to agents.
Keep the observability.

klaridian generates a Model Context Protocol server straight from your OpenAPI spec — with OpenTelemetry tracing wired in from the first tool call, not bolted on afterward.

Curate the surface

03

Ship, instrumented

A stateless MCP server with OTel spans on every tool call. Plug in Datadog or Grafana.

Read it before you trust it

Open source, MIT-licensed generator. The server it produces is plain, auditable TypeScript — no closed binary running next to your agent with real credentials.
